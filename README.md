# Sanse 的 Omni 在线模块仓库

本仓库发布 **园圃工作台 · Omni 版 1.0.2**，作者 **Sanse**。

## 安装

1. 安装或更新 Omni Toolbox，最低版本 **1.1.8.9**。
2. 在 Omni 的 **插件设置 → 在线模块** 中添加以下仓库地址：
   `https://github.com/KKsanse/OmniToolbox.sanse`

3. 刷新仓库，安装「园圃工作台」。
4. 在 **树树妙妙屋 → 在线** 中手动启用模块，首次安装默认关闭。
5. **需要开启自动跳过对话。**

如需直接填写清单地址：

```text
https://raw.githubusercontent.com/KKsanse/OmniToolbox.sanse/main/TreeHouseModules.json
```

## 模块列表

- **园圃工作台**  — 按格选择种子与土壤，保存杂交布局；支持多园圃管理、护理施肥、作物识别与到期提醒。需要开启自动跳过对话。
